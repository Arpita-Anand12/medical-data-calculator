 Medical Data Calculator

A beginner-friendly Python project that calculates basic health and wellness measurements through a simple menu-driven program.

🧮 Features

The program includes:

- BMI Calculator — Calculates Body Mass Index and displays a category.
- BMR Calculator — Estimates Basal Metabolic Rate.
- Blood Pressure Classifier — Provides an educational blood pressure category.
- Heart Rate Calculator — Estimates maximum heart rate and target heart rate range.
- Waist-to-Hip Ratio Calculator — Calculates the waist-to-hip ratio.
- Input Validation — Handles invalid and negative inputs.
- SQLite Database — Saves calculation results locally.

🛠️ Technologies Used

- Python
- SQLite
- PyCharm
- Git and GitHub

▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project in PyCharm or another Python editor.
4. Run the "main.py" file.
5. Follow the menu instructions in the terminal.

The SQLite database file will be created automatically when the program runs.
